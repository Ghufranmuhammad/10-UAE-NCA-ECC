# UAE NCA ECC Domains Summary

## 1. Cybersecurity Governance

### Purpose
Establish cybersecurity strategy, policies, leadership, and accountability.

### Business Value
Ensures cybersecurity supports business objectives and regulatory compliance.

### Example Implementation
Information Security Policy approved by executive management.

### Audit Evidence
Approved policies, governance committee meeting minutes, organization chart.

---

## 2. Cybersecurity Defense

### Purpose
Protect systems, applications, and information from cyber threats.

### Business Value
Reduces the likelihood of cyber attacks and data breaches.

### Example Implementation
Multi-Factor Authentication, endpoint protection, vulnerability management.

### Audit Evidence
MFA reports, vulnerability scan reports, endpoint protection dashboards.

---

## 3. Cybersecurity Resilience

### Purpose
Ensure the organization can respond to and recover from cyber incidents.

### Business Value
Minimizes operational disruption and supports business continuity.

### Example Implementation
Disaster Recovery Plan and regular backup testing.

### Audit Evidence
Backup logs, disaster recovery test reports, incident response reports.

---

## 4. Third-Party & Cloud Security

### Purpose
Manage cybersecurity risks associated with suppliers and cloud service providers.

### Business Value
Reduces supply chain and cloud-related security risks.

### Example Implementation
Vendor security assessments and cloud security reviews.

### Audit Evidence
Vendor assessment reports, contracts, cloud configuration reviews.
