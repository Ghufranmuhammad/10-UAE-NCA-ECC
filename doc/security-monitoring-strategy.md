# Security Monitoring Strategy

## Monitoring Objectives

- Detect cyber threats quickly.
- Monitor critical business systems.
- Support incident response.
- Meet regulatory and compliance requirements.

---

## Log Sources

- Firewalls
- Windows Servers
- Microsoft Entra ID
- Microsoft 365
- Endpoint Detection and Response (EDR)
- VPN
- Email Security Gateway
- Web Proxy

---

## Alerting Process

1. Security event detected.
2. SIEM generates an alert.
3. SOC analyst validates the alert.
4. Incident is classified.
5. Incident Response Team is notified if required.

---

## Roles and Responsibilities

| Role | Responsibility |
|------|----------------|
| SOC Analyst | Monitor alerts and investigate events |
| Security Engineer | Tune detection rules |
| CISO | Review security metrics |
| IT Team | Support remediation |
| GRC Manager | Monitor compliance and reporting |

---

## Incident Escalation

- Low → SOC Analyst
- Medium → Security Engineer
- High → Incident Response Team
- Critical → CISO and Executive Management

---

## Review Frequency

- SIEM Monitoring: Daily
- Critical Alerts: Real-time
- KPI Review: Monthly
- Executive Reporting: Quarterly
