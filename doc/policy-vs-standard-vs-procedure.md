# Policy vs Standard vs Procedure vs Guideline

Understanding the difference between policies, standards, procedures, and guidelines is an important GRC skill.

| Document | Purpose | Example |
|---|---|---|
| Policy | Defines what the organization requires and why | Access Control Policy |
| Standard | Defines specific mandatory requirements | MFA Standard |
| Procedure | Defines how an activity is performed | User Access Review Procedure |
| Guideline | Provides recommended good practices | Secure Password Guideline |

---

## 1. Policy

### What is it?

A policy establishes high-level organizational requirements and management expectations.

It answers:

**What must we do, and why?**

### Example

An Access Control Policy may require DesertTech to restrict access based on business need and least privilege.

---

## 2. Standard

### What is it?

A standard translates policy requirements into specific mandatory requirements.

It answers:

**What specific requirement must be met?**

### Example

An MFA Standard could require MFA for:

- Privileged accounts
- Remote access
- Cloud administration

---

## 3. Procedure

### What is it?

A procedure explains the steps employees or teams follow to perform an activity consistently.

It answers:

**How do we do it?**

### Example

A User Access Review Procedure could explain:

1. Export current users.
2. Identify system owners.
3. Review user permissions.
4. Identify excessive access.
5. Obtain approval.
6. Remove inappropriate access.
7. Save evidence.

---

## 4. Guideline

### What is it?

A guideline provides recommended practices rather than strict mandatory requirements.

It answers:

**What is a recommended way to perform an activity?**

### Example

A Secure Password Guideline may recommend using long, unique passwords and avoiding password reuse.

---

# Simple Interview Answer

If an interviewer asks:

**"What's the difference between a policy, standard, procedure, and guideline?"**

A strong answer is:

> "A policy defines what the organization requires and why. A standard defines specific mandatory requirements. A procedure explains how to perform the activity step by step. A guideline provides recommended good practices. For example, an Access Control Policy could require least privilege, an MFA Standard could require MFA for privileged accounts, a User Access Review Procedure could explain how to conduct the review, and a Secure Password Guideline could provide recommended password practices."
